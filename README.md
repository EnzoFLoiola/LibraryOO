# 📚 Biblioteca OO em Python

Este projeto foi criado para consolidar os conhecimentos adquiridos na **formação de Orientação a Objetos com Python da Alura**. A ideia surgiu como um exercício prático e foi desenvolvido em aproximadamente 2 horas.

## 🧠 Objetivo

Praticar os conceitos de orientação a objetos, como:
- Encapsulamento
- Composição de objetos
- Métodos e atributos privados
- Reuso de código
- Organização modular com pacotes e classes

## 🚀 Como funciona

A aplicação simula uma biblioteca simples com as funcionalidades:

- Cadastro de usuários
- Cadastro de livros
- Empréstimo de livros
- Devolução de livros
- Listagem de livros emprestados por um usuário
